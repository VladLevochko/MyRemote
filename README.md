# MyRemote

Пульт на телефоні для MacBook, підключеного до телевізора: play/pause, перемотка,
гучність, fullscreen, навігація стрілками і трекпад для всього іншого.

| Частина | Де | Що це |
|---|---|---|
| Mac-агент | [`mac/`](mac/) | Menu bar застосунок на Swift: WSS-сервер, Bonjour, інжект клавіш і миші |
| Android-клієнт | [`android/`](android/) | Kotlin + Compose: сам пульт |
| Контракт | [`docs/PROTOCOL.md`](docs/PROTOCOL.md) | Протокол v1, якого дотримуються обидві сторони |
| Фікстури | [`protocol/fixtures/`](protocol/fixtures/) | Спільні тестові повідомлення для контрактних тестів |

Інструкції зі збирання, тестів і запуску — у README кожної частини.
