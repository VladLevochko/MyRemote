# Контрактні фікстури

- `client/*.json` — валідні повідомлення клієнт → сервер.
- `server/*.json` — валідні повідомлення сервер → клієнт.
- `pairing/cases.json` — валідні й невалідні pairing URI.

Обидві реалізації мусять: розпарсити кожну фікстуру у типізовану модель,
серіалізувати назад і отримати семантично той самий JSON (порядок ключів неважливий).
